# Storyling 📖🎧

**Your next story teaches you.**

Storyling is an adaptive AI audiobook platform for language learning. Users choose a target language, CEFR level, and interests, then receive personalized stories with audio, comprehension practice, vocabulary review, and adaptive repetition.

## Product vision

- Personalized AI-generated stories
- English and other target languages
- CEFR levels A1-C1
- Realistic text-to-speech audio
- Adjustable playback speed
- Comprehension quizzes
- Vocabulary tracking and spaced repetition
- Short transcription/listening practice
- Progress dashboard
- Free beta with no subscriptions initially

## Planned stack

- React + Vite
- Tailwind CSS
- Supabase for database and authentication
- Groq for story generation
- Pluggable TTS provider for audio
- GitHub for version control
- Vercel for deployment

## Project status
